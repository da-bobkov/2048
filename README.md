# 2048 Game (Windows Forms / C#)

[![NET Version](https://img.shields.io/badge/.NET-8.0-purple.svg)](https://dotnet.microsoft.com/)
[![Language](https://img.shields.io/badge/Language-C%23-blue.svg)](https://learn.microsoft.com/en-us/dotnet/csharp/)
[![Platform](https://img.shields.io/badge/Platform-Windows%20Forms-green.svg)](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/)

Реализация культовой головоломки **2048**, разработанная на платформе Windows Forms (C#). 

---

## 🚀 Особенности проекта

* **Классический геймплей:** Полное соответствие оригинальной механике 2048 (объединение плиток с одинаковыми номиналами, генерация новых двоек/четверок).
* **Система рекордов:** Автоматическое сохранение лучшего результата (High Score) между сессиями (через сериализацию в JSON).
* **Управление:** Поддержка управления стрелочками на клавиатуре.
* **UI:** Стилизация с правильной цветовой палитрой для каждого номинала плитки.
